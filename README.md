\# Online Examination System



A Java Web based Online Examination System developed using JSP, Servlet and MySQL.



\## Project Description



Online Examination System is a full-stack Java web application that allows students to register, login, attempt online exams and view their results instantly.



\## Features



\- Student Registration and Login

\- User Authentication

\- Online Exam System

\- Multiple Choice Questions

\- Automatic Result Generation

\- Student Profile Management

\- Admin Panel

\- Question Management

\- Course Management



\## Technologies Used



\- Java

\- JSP

\- Servlet

\- MySQL

\- HTML

\- CSS

\- Bootstrap

\- JavaScript

\- Apache Tomcat

\- NetBeans IDE



\## Database



MySQL database is used for storing:

\- Student details

\- Questions

\- Exam records

\- Results



\## How to Run



1\. Install NetBeans IDE

2\. Configure Apache Tomcat Server

3\. Import MySQL database

4\. Update database connection details

5\. Run the project on Tomcat Server
